# 数据模型: 登录接口测试

## 测试输入模型

### LoginRequest
| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| username | String | 是 | 登录用户名 |
| password | String | 是 | 登录密码 |

**校验规则**:
- username 和 password 均不可为 null
- 空字符串 ("") 视为参数存在但无效，与缺失字段同等处理

## 测试输出模型

### LoginResponse
| 字段 | 类型 | 成功时值 | 失败时值 |
|------|------|----------|----------|
| code | int | 200 | 401 |
| message | String | "登录成功" | "用户名或密码错误" |
| token | String | "fake-jwt-token" | null |

## 状态矩阵

| 场景 | username | password | 期望 code |
|------|----------|----------|-----------|
| 正确凭据 | "admin" | "123456" | 200 |
| 错误密码 | "admin" | "wrong" | 401 |
| 错误用户名 | "hacker" | "123456" | 401 |
| 全部错误 | "hacker" | "guess" | 401 |
| 缺少 username | (缺失) | "123456" | 401 |
| 缺少 password | "admin" | (缺失) | 401 |
| 空 username | "" | "123456" | 401 |
| 空 password | "admin" | "" | 401 |
| 空请求体 | (无字段) | (无字段) | 401 |
| null username | null | "123456" | 401 |
| SQL注入用户名 | "' OR '1'='1" | "123456" | 401 |
| SQL注入密码 | "admin" | "' OR '1'='1" | 401 |
| XSS注入 | "<script>..." | "123456" | 401 |
| 超长用户名 | "a"×10000 | "123456" | 401 |
| 特殊字符密码 | "admin" | "!@#$%^&*()" | 401 |
| Unicode用户名 | "管理员" | "123456" | 401 |
| 多余字段 | "admin"+"extra" | "123456" | 200 |
